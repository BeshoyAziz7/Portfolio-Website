## ⚡ What is this?

This isn't a template. It's a hand-built, scroll-driven, canvas-clipped, GSAP-animated corner of the internet — a portfolio that treats scrolling as a camera move rather than a page turn.

You'll walk *through* a giant letterform to enter the site, scroll through a four-chapter origin story, spin a coverflow carousel of skills, watch a stack of project cards scatter across the screen, and land on a footer that breathes.

No frameworks. No build step. Just HTML, CSS, and JavaScript doing things they're not usually asked to do.

---

## 🧭 The Journey

| # | Section | What happens |
|---|---------|---------------|
| `01` | **Glyph Portal** | Your name is a giant clipped glyph. Scroll, and the camera zooms *through* the letterform into the site. |
| `02` | **Origin Story** | A pinned, scroll-scrubbed narrative across four chapters — Origin → Research → Toolkit → Vision — with live counters and shifting accent colors. |
| `03` | **Skills Coverflow** | A draggable, swipeable 3D carousel of six disciplines, each with animated proficiency bars. |
| `04` | **Stack Spread** | Project cards scatter from a single stack into a full spread as you scroll, then snap together into a modal on click. |
| `05` | **Motion Footer** | A curtain-reveal footer with a diagonal marquee, magnetic buttons, and giant parallax type. |

## 🛠️ Built With

```
HTML5           — semantic structure, zero build tooling
CSS3            — custom properties, scroll-driven visuals, clip-path glyph masking
JavaScript      — vanilla, no frameworks
GSAP + ScrollTrigger — the engine behind every scroll-tied animation
```

No React. No Vue. No bundler. Open `index.html` and it just works.

---

## 📂 Structure

```
.
├── index.html      → markup & content
├── styles.css       → design system, layout, animation
├── script.js        → interactivity & scroll-driven logic
└── Images/           → portrait & media assets
```

Three files. That's the whole stack. Clone it, open it, edit it.

---

## 🚀 Running It Locally

```bash
git clone https://github.com/BeshoyAziz7/portfolio.git
cd portfolio
```

Then just open `index.html` in a browser — or, for smoother asset loading, serve it locally:

```bash
npx serve .
```
